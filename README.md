# PoseSketch

Браузерный 3D-конструктор статичных поз для рисования. Русский интерфейс, без сервера, учётной записи и внешних API.

## Запуск

Нужен Node.js 22.12+ (проверено на 24.22.1).

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Производственная сборка: `npm run build`, результат в `dist/`. Размещать можно на статическом хостинге.

## Управление

- Выберите позу в мастерской, затем сустав на фигуре или часть тела в редакторе поз.
- Стрелки у панелей скрывают и возвращают мастерскую и редактор поз при любой ширине окна, включая «Версию для ПК» на телефоне. Слева `<` скрывает и `>` открывает мастерскую; справа `>` скрывает и `<` открывает редактор. На узком экране панели открываются поверх сцены по одной; их можно закрыть стрелкой, нажатием на затемнённый фон или Escape. Настройка запоминается после обновления страницы. Поза и камера при сворачивании сохраняются.
- Ладонь (H или Escape) — обзор: касания, щелчки по суставам и перетаскивания в сцене управляют камерой, сохраняя текущую позу. Манипулятор и маркеры выбора скрыты. Для возвращения к постановке нажмите W или E; числовые параметры и команды позы остаются доступны для явного редактирования.
- W — перемещение, E — вращение. Каждая часть тела запоминает выбранный инструмент на время сеанса; выбор колена не меняет инструмент стопы. Для кистей и стоп по умолчанию включено вращение; для IK-перемещения нажмите W. Тяните цветную ось или плоскость манипулятора. Координаты X/Y/Z позволяют точно задать глубину.
- Кисти и стопы управляют двухсегментной IK. Ползунок направления сгиба поворачивает локоть/колено вокруг оси конечности. Недостижимые цели ограничиваются радиусом досягаемости; поле хранит целевую координату.
- Плечи и тазобедренные суставы выбираются щелчком или списком: вращение XYZ поворачивает конечность целиком вокруг её основания. Локти и колени выбираются отдельно: перемещение направляет верхний сегмент, вращение направляет предплечье/голень, поле «Сгиб» задаёт угол. Кисть/стопа следует за суставом; длины сохраняются. Для плеча включается вращение, для локтя — перемещение.
- Вся фигура перемещается и вращается целиком. Таз, грудная клетка и голова вращаются отдельно; положение кистей и стоп задано в системе всей фигуры. При повороте корпуса IK сохраняет цели.
- Камера: тяните фон, колесо — масштаб, правая кнопка — смещение. Сенсорный экран: один палец вращает камеру, два масштабируют и смещают. Для позы используйте манипулятор или числовые поля.
- Быстрые ракурсы, изометрия, ортография/перспектива и показ фигуры целиком находятся в рабочей области.
- «Объём» показывает стилизованный человеческий манекен: грудная клетка, талия, таз, шея, голова с лицевой плоскостью, носом, челюстью и подбородком, плавные профили рук и ног. По умолчанию он непрозрачный; «Скелет поверх» включает полупрозрачный объём с линиями скелета. Стопы имеют пятку, подъём и пальцы в обоих режимах.
- Ctrl/⌘+Z — отмена, Ctrl/⌘+Shift+Z — повтор. История до 100 шагов; после обновления сохраняется поза, но не история.
- JSON версии 1 сохраняет позу; PNG сохраняет текущий ракурс без манипулятора и маркеров выбора. Сетка остаётся в PNG. Автосохранение — localStorage текущего браузера.

## Проверки

```sh
npm run build
npm test
npm run test:e2e
```

Браузерные тесты используют `/usr/bin/chromium`. На другой машине задайте доступный браузер в `playwright.config.ts` либо удалите `executablePath` и выполните `npx playwright install chromium`. Dev-сервер тесты запускают автоматически.

Архитектура и ограничения: [docs/PROJECT.md](docs/PROJECT.md). Состояние реализации: [docs/STATUS.md](docs/STATUS.md).

## GitHub Pages

Публичный адрес: https://ygadalov.github.io/pose-sketch/.

В репозитории откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**. Workflow `.github/workflows/pages.yml` при каждом push в `main` запускает тесты и сборку и публикует только `dist/`. При необходимости запустите его вручную: **Actions → Deploy PoseSketch to GitHub Pages → Run workflow**.

`vite.config.ts` задаёт `/pose-sketch/` для production-ресурсов. Dev-сервер работает с `/`. Публикация исходной ветки `main` напрямую не подходит: браузер не выполняет исходный TypeScript приложения.
