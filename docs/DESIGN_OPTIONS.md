# Варианты оболочки PoseSketch

Интерактивная галерея: `/designs/`. Текущий редактор не изменён.

| Вариант | Характер | Для кого |
| --- | --- | --- |
| Atelier | Светлая мастерская, спокойная зелёная палитра, Manrope, привычные боковые панели | Начинающие художники; рекомендуемое базовое направление |
| Graphite | Тёмный рабочий интерфейс, Golos Text, компактная панель команд | Пользователи графических и 3D-редакторов |
| Folio | Бумажный фон, Literata, плавающие карточки, свободная композиция | Художники, которым важнее референс и атмосфера мастерской |

Все варианты показывают одинаковую исходную позу и поддерживают просмотр на компьютере и телефоне. Работают вращение камеры, ракурсы, три готовые позы, объём/линии, проекция, сетка, параметры корпуса и PNG. Это макеты для выбора визуального направления, не полная замена функций редактора. Данные основного редактора не затрагиваются.

Шрифты хранятся локально; лицензии OFL находятся рядом с ними в `public/designs/fonts/`. Снимки макетов лежат в `public/designs/previews/`.
