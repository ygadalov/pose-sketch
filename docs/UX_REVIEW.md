# Проверка UX/UI PoseSketch — 7 ноября 2026

Проверены: первый запуск, выбор и изменение позы, управление камерой, числовой ввод, история, импорт/экспорт, мобильные панели, доступность элементов управления. Рабочие ширины: 320, 390, 768, 844, 1024 и 1440 px; отдельно сохранён тест широкого viewport 980 px на телефоне («Версия для ПК»).

## Находки и исправления

| Приоритет / принцип | Что мешало | Что изменено |
| --- | --- | --- |
| Высокий: предотвращение ошибок | При старте был включён инструмент изменения позы | По умолчанию активна ладонь. Текущий инструмент явно подписан; неподдерживаемое перемещение закреплённого сустава недоступно |
| Высокий: управление с клавиатуры | После ввода координаты и Tab фокус оказывался на BODY | Значения обновляются без замены полей. Tab переходит к следующей координате; последовательные изменения плеча сохраняют предыдущие оси |
| Высокий: доступность функций | «Скелет поверх» был полностью скрыт на телефоне | Переключатель доступен в режиме «Объём» на всех ширинах; в «Скелете» лишний переключатель не показывается |
| Средний: правдивый статус | После изменения позы оставался выделен исходный пресет | Состояние сравнивается с реальной позой. Показывается «Моя поза» либо точное имя совпавшего пресета, включая undo, импорт и восстановление |
| Средний: правдивый статус камеры | Кнопка ракурса оставалась активна после свободного вращения; изометрия не обновляла остальные кнопки | Выделение следует фактическому направлению камеры. Быстрые ракурсы останавливают инерцию, изометрия и «Показать целиком» обновляют статус |
| Средний: обратная связь | Числовая IK-цель могла быть недостижимой без пояснения | Редактор объясняет, что конечность показывает ближайшее доступное положение |
| Средний: читаемость и доступность | Контраст отдельных текстов был 2.19–4.22:1; переключатель ограничений не имел имени | Исправлена палитра подписей и полей. Добавлены доступные имена, состояния кнопок, имя диалога помощи и заметный клавиатурный фокус |
| Средний: размер референса | Вписывание по сфере излишне уменьшало фигуру на узком экране | Вписывание использует реальные габариты в координатах камеры; учитываются и верхние настройки, и нижняя панель |
| Средний: адаптивная компоновка | Нижняя панель ракурсов имела фиксированное зарезервированное место и могла пересекать сцену при переносе строк | Рабочая область учитывает фактическую высоту панели через ResizeObserver; подпись позы остаётся над панелью |
| Средний: мобильная клавиатура | Фокус мог уходить под открытую панель; Escape попутно менял инструмент | Фон сцены становится inert, Tab остаётся в доступных элементах панели и её переключателях, закрытие возвращает фокус. Escape панели/помощи не меняет инструмент |
| Низкий: информационная иерархия | Повторяющиеся заголовки и рекламные блоки занимали место; JSON описывал формат вместо задачи пользователя | Панели сокращены. Действия называются «Сохранить позу» / «Загрузить позу»; формат указан в подсказке |
| Низкий: визуальная ясность | Некоторые символьные стрелки отображались квадратиками; кнопка PNG переносилась на маленьком экране | Для экспорта и пресетов используются SVG. На узком экране кнопка компактно подписана PNG, полное название доступно скринридеру |
| Средний: результат операции | Сообщение об успешном PNG появлялось до окончания кодирования | Кнопка ждёт готовый Blob, блокирует повторный запуск и сообщает о результате; предусмотрено сообщение при ошибке |

## Проверка результата

- `npm run build` — типизация и production-сборка.
- `npm test` — 7 тестов модели и геометрии.
- `npm run test:e2e` — 14 браузерных сценариев, включая четыре новых UX-регрессии.
- axe-core: в проверенных состояниях нет нарушений выбранных правил WCAG A/AA (desktop, помощь, мобильный объём, мобильный редактор).
- Вручную просмотрены скриншоты обычного телефона, мобильного объёма и редактора, компактного экрана 320 px и рабочего стола.
- Камера доступна с клавиатуры: стрелки на сфокусированной рабочей области смещают её без изменения позы.

Это технический аудит и проверка сценариев в Chromium, а не сертификация полного соответствия WCAG или исследование с пользователями. Отдельная проверка на физических iOS/Android-устройствах, VoiceOver/TalkBack и наблюдение за начинающими художниками остаются следующими способами оценить удобство. Объём изменений намеренно ограничен интерфейсом и обратной связью; модель позы и JSON-формат сохранены.
